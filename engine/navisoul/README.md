# Navi Soul engine source checkpoint

This directory preserves the new Astro engine and its tests. The deployed NaviOS UI remains the existing Next.js application at the repository root. The shared Office document extractor is now imported by the root application's browser worker. The other engine modules are not yet connected to that production UI; do not treat this source checkpoint as a full migration.

Run `npm ci`, `npm run check`, `npm test`, and `npm run build` in this directory. Runtime bundles are generated by the package scripts. Generated bundles, dependencies, build output, and credentials are deliberately excluded from this snapshot.

Implemented modules include the bounded inference router, declarative MCP/REST tool registry, incremental stream parser, document workers, local document retrieval and embeddings, versioned IndexedDB storage, artifact canvas, and isolated HTML/React/Vue/diagram/math runtimes.

Verified locally: React and Vue counters update, Mermaid renders, and isolated JavaScript returns 42. Astro diagnostics passed with zero errors and warnings. See the root checkpoint for remaining integration and release work. This does not establish frontier-model parity, universal connector access, production authentication readiness, premium voice, or free unlimited inference.

Preserve the existing NaviOS design during integration. Integrate and verify one execution path at a time; do not replace the root UI with this test interface.
